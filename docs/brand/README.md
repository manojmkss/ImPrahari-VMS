# ImPrahari brand

| File | Use |
|---|---|
| `imprahari-logo.png` | **The final logo (master file)**: emblem, the ImPrahari wordmark and "Open-source home NVR". README header, posts, slides. Every other image here and every app icon is made from it. |
| `imprahari-emblem-512.png` | The shield emblem alone, square, on the logo's navy (`#011129`). Avatars, app stores. |
| `imprahari-social-preview.png` | 1280 x 640, for GitHub's link previews (repository Settings → General → Social preview). |

The app icons are made from the logo, so they always match it:

- web app: `frontend/public/icons/` (browser tab, installed app, iPhone home screen, push badge) and `frontend/public/favicon.ico`;
- Android app: `android/app/src/main/res/mipmap-*/ic_launcher_foreground.png` (launcher icon), `ic_launcher_monochrome.png` (Android 13+ themed icons) and `drawable-nodpi/logo_emblem.png` (sign-in screen);
- Home Assistant: `homeassistant/brand/`.

Writing the name: **ImPrahari** (capital I, small m, capital P), read "I'm Prahari". *Praharī* (प्रहरी) is the Sanskrit and Hindi word for a watchman.
